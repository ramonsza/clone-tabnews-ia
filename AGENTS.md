# clone-tabnews-ia

Clone do [TabNews](https://tabnews.com.br), site de conteúdos sobre tecnologia e programação, construído com a ajuda de agentes de IA para implementar os recursos dele.

## Stack

- Next.js 16 com App Router
- React 19

## Comandos

- `npm run dev`: inicia o servidor de desenvolvimento
- `npm run build`: gera o build de produção
- `npm start`: serve o build de produção
